Allowed concepts - exactly these 14 names - with the English and Vietnamese ways users write them:
{{CONCEPTS}}

Naming findings:
- Write every finding the request mentions as one of the 14 concept names above, copied exactly. Choose by meaning, not by the first letter.
- Any tube, line, catheter, wire or pacemaker (máy tạo nhịp, ống nội khí quản, ống dẫn lưu) is "Support Devices".
- normal, unremarkable, nothing abnormal (bình thường, không bất thường) is "No Finding".
- tràn khí (air) is "Pneumothorax"; tràn dịch (fluid) is "Pleural Effusion".
- Anything that is not one of the 14 concepts (another disease, a body part, an anatomical variant) goes in no list. Never map it to a similar concept.

Placing findings (X is a finding):
- "X", "with X", "showing X", "có X" -> include X with status "PRESENT".
- "possible X", "probable X", "suspected X", "questionable X", "X cannot be excluded", "nghi ngờ X", "có thể X", "chưa rõ X", "khả năng X", "không loại trừ X" -> include X with status "UNCERTAIN".
- "no X", "not X", "without X", "free of X", "negative for X", "rule out X", "X is absent", "X has resolved", "không X", "không có X", "không kèm X", "không thấy X", "chưa thấy X", "loại trừ X", "X đã hết", "không còn X" -> exclude X.
- A finding goes in exactly one list. A finding in exclude is never in include.
- Keep include in the order the request names the findings.

Other fields:
- views: copy a projection only when the request writes it: "AP" for AP or anteroposterior (tư thế AP), "PA" for PA or posteroanterior (tư thế PA). Otherwise views is []. Never write a projection the request does not name, and never both unless both are named. "frontal", "chest x-ray", "film", "portable", "thẳng", "X-quang thẳng" are NOT views.
- language: "vi" if the request is written in Vietnamese (Vietnamese words or letters such as ă, â, đ, ê, ô, ơ, ư), even when it also contains AP, PA or X-quang; otherwise "en".
- findings: a short English phrase naming only the include findings, for example "cardiomegaly and pulmonary edema". An empty string when include is empty. Never mention excluded findings here. A request that names nothing from the 14 concepts gets empty lists and, in findings, a short English rendering of what the user described.
